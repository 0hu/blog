클로저
클로저는 주변 상태(어휘적 환경)에 대한 참조와 함께 묶인(포함된) 함수의 조합입니다. 즉, 클로저는 내부 함수에서 외부 함수의 범위에 대한 접근을 제공합니다. JavaScript에서 클로저는 함수 생성 시 함수가 생성될 때마다 생성됩니다.

mdn에 나오는 정의이다. 이게 도대체 무슨 말인가 싶다.

어휘적 환경 ..? 참조와 함께 묶인 함수의 조합이라고 한다.

그리고 내부 함수에서 외부 함수의 범위에 대한 접근을 제공합니다.. 라고 한다.
그리고 함수 생성시 함수가 생성될 때마다 생성 된다.

스코프 - 생존범위이다.

```js
function dosomething() {
  const fruit = "apple";

  return function didsomething() {
    const name = "huhu";
    console.log(fruit + name);
  };
}

const doing = dosomething();
doing();
```

doing 을 실행하면 dosomething return 뒤에 값을 반환 받고 종료를 하게 되는데.

didsomething 내에서 console.log() 내에서 fruit를 사용하고 있습니다.

여전히 fruit를 참조 하고 있어 dosomething을 종료 하더라도 didsomething 내에서 fruit 사라지지않고 사용하고있습니다.

doing 변수에 didsomething 함수가 할당 될 때 그 때!!!!!!!!를 기억한다. 그 때의 lexical enviroment에 대한 참조를 저장!!!

```js
import { useEffect, useState } from "react";

export default function useScroll() {
  const [isBottom, setIsBottom] = useState(false);

  useEffect(() => {
    function throttling(callback, delay) {
      let timer = null;

      return () => {
        if (timer === null) {
          timer = setTimeout(() => {
            callback();
            timer = null;
          }, delay);
        }
      };
    }

    // 스크롤 핸들러 함수
    const handleScroll = () => {
      // 바닥 도달 확인
      const isAtBottom =
        window.innerHeight + document.documentElement.scrollTop + 20 >=
        document.documentElement.offsetHeight;

      setIsBottom(isAtBottom);
    };

    // 쓰로틀된 스크롤 핸들러 생성 (100ms 지연)
    const throttledScrollHandler = throttling(handleScroll, 100);

    // 이벤트 리스너 등록
    window.addEventListener("scroll", throttledScrollHandler);

    // 클린업
    return () => {
      window.removeEventListener("scroll", throttledScrollHandler);
    };
  }, []);

  return isBottom;
}
```

const throttledScrollHandler = throttling(handleScroll, 100);

실행 되면 throttling 함수가 반환하는 내부 함수(return 안의 부분)가 throttledScrollHandler 변수에 저장됩니다.

이 때!!!! 반환된 함수가 저장되는데, 이 함수는 `timer`, `callback`, `delay` 등 변수뿐만 아니라 매개변수까지 포함된 `throttling` 함수의 어휘적 환경(Lexical Environment) 전체를 기억하는 클로저가 생성됩니다.

이때!!!를 기억한다.

처음에 이해가 잘 안됐던 부분은 스크롤할때  
throttling 함수의 return 이 계속 실행되는 것이 아니냐고 생각했습니다.
실행되면서 timer 의 아이디가 계속 할당되는데 그럼 timer 가 null 이 될 수 가 있나 싶었다.

일단 timer는 처음 id 값을 가지고 시작하고
settimeout으로 1초가 흐르기전 까지 timer는 if 문 안으로 들어가지못합니다 왜냐하면 timer를 기억하고 있기 때문에 그래서 1초가 흐르면 callback 이 실행 되고 timer 가 null 이 되는겁니다.
